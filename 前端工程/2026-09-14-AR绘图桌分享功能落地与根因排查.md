# Taro 小程序分享功能落地与"当前页面不可分享"根因排查

## 问题背景

AR 绘图桌首页（Taro 4.2.1 + Vue3 + Skyline 渲染器）需要支持转发好友与分享朋友圈。在 `<script setup>` 中注册分享回调并编译通过后，Android 真机点击"分享到朋友圈"仍提示"当前页面不可分享"。本文记录从组合式 hook 用法、Taro 编译链路约定字段、朋友圈单页模式到云开发未登录访问的完整排查链路。

## 根因排查（源码链路）

组合式 hook 是前提：Taro 的 `<script setup>` 必须用 `useShareAppMessage` / `useShareTimeline` 注册；直接写 `onShareAppMessage` 选项不会被 Page 收集。

"当前页面不可分享"的真正根因在页面 config 约定字段缺失，逐层读源码确认：

- `@tarojs/taro-loader/lib/page.js`：仅当 `config.enableShareTimeline` 为真，才注入 `component.enableShareTimeline = true`。
- `@tarojs/runtime` 的 `createPageConfig`：注释明确 `onShareAppMessage` / `onShareTimeline` 会影响右上角按钮选项、故默认不注册；仅当 ① `component.onShareTimeline` ② `prototype.onShareTimeline` ③ `component.enableShareTimeline` ④ `pageConfig.enableShareTimeline` 任一成立，才定义 `config.onShareTimeline = function(){...}`。
- 本例使用 hook，前三条不满足；页面 config 未声明那两个字段 → 第四条不成立 → `config.onShareTimeline` 未定义 → 微信判定页面未开启朋友圈分享。

修复：在 `src/pages/index/index.config.js` 增加 `enableShareAppMessage: true`、`enableShareTimeline: true`（Taro 约定字段，生成小程序 `.json` 时由 MiniPlugin 删除，属正常；文件内必须写注释说明不可删）。

## 单页模式（scene 1154）适配

朋友圈打开进入单页模式：跳转 API 全禁用、storage 隔离、自定义导航栏默认被系统栏 `float` 覆盖。改动如下：

- `index.config.js` 增加 `singlePage: { navigationBarFit: 'squeezed' }`（首页为 custom 导航，不设会被系统栏盖住 hero 区）。
- `index.vue`：同步判定 `isSinglePage`（scene === 1154）、`guardJump()` 拦截全部跳转入口、`useDidShow` 跳过新手引导、增加单页提示条。

## 云开发未登录访问（errCode -501023）

单页模式等于微信官方定义的"未登录模式"，默认拒绝云资源，报 `-501023 permission denied`。本项目首页经云函数 `lineart` 取数（`wx-server-sdk` 管理员权限、绕过 C 端安全规则），故只需两步：

1. 云开发控制台 → 设置 → 权限设置 → 开启"未登录用户访问云资源"。
2. 云函数安全规则（自定义）：

```json
{ "*": { "invoke": "auth != null" }, "lineart": { "invoke": true } }
```

只放开只读的 `lineart`，`admin` / `secCheck` 不放开（否则绕过登录即可写数据）。数据库 / 文件存储安全规则无需改动：全项目无页面直连数据库，素材 `fileId` 存的是 https URL 而非 `cloud://` fileID。

## 工程复盘

- 查编译产物要搜 hook 名（`useShareAppMessage`）而非回调名（`onShareAppMessage`），否则误判未编译。
- production 产物函数名被 minify、中文转 `\uXXXX`，需搜 `1154` / `duration:2400` / `showToast` 等字面量。
- 云函数安全规则三个入口语法不同（集合 read/write、云函数 invoke、存储 read/write），粘错页报 `InvalidParameter, rule invalid`；集合规则不支持 `auth != null`（`null` 不在官方变量表）。
- 全局预设放开是否安全，取决于云函数内服务端鉴权：本项目 `admin` 除 `whoami` 外均先 `isAdmin(openid)`（openid 取自 `getWXContext()`、前端伪造不了），未登录写不进；已给 `whoami` 加 `if (!openid) return {...}` 防御空记录。
- 分享封面：好友 5:4、朋友圈 1:1 比例不同不能共用；原图主体内切需缩到贴合高度再补底色，PIL 负坐标 `crop` 静默填黑边，须改用 `Image.new` + `paste`。
